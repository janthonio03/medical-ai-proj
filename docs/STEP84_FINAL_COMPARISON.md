# CAST 논문 지향 구현과 공개 방식 비교 — 최종 해석

2026-11-22 KST. 고정 SLAKE English test 1,061문항과 96개 이미지에서 시험한 조건을 평가했다. STEP80의 9조건과 STEP81의 통계 분석에 STEP82 문자열 채점 감사, STEP83 위치/RoPE 진단, STEP84 전체 공통 위치 대조를 반영했다.

## 최종 결과

- 관측 최고 CLOSED 점수는 Draft·actual bias·Temporal ON **73.80점**, OPEN 최고는 Draft·Public B1·Temporal OFF **45.14점**이다.
- 논문 지향 후보와 수리한 공개 기본 endpoint의 차이는 CLOSED **+5.53점**(95% 구간 +2.46~+8.74), OPEN **−2.96점**(−5.59~−0.18)이다. OPEN의 감소는 STEP81의 다중 대비 근사 동시 구간에서 0을 포함했다. 전체 우열은 지표별 상충 관계로 보고한다.
- GT와 Draft의 ROI가 566문항에서 달랐다. 다른 요소를 균등 평균한 GT−Draft 점수 차이는 CLOSED +0.06점, OPEN −0.02점이다. 두 구간 모두 0을 포함했다.
- 공통 위치 B2에서도 Temporal은 CLOSED **+4.33점**(95% +1.46~+7.41) 상승했다. OPEN은 **−1.90점**(−4.32~+0.61)으로 추정됐으며 0을 포함했다. STEP81 전체 요인 평균에서 관측된 OPEN 감소를 모든 구현에 일반화하기 어렵다.
- B2로 위치를 통일한 뒤 actual bias와 비교해도 모든 95% 구간이 0을 포함하거나 경계에 닿았다. 두 구현의 실행 경로가 달라 이 대비에 여러 경로 차이가 포함된다.

## STEP84 공통 위치 민감도

B2는 B1의 padding guard 수정과 양수 마스크를 유지하면서 두 분기에 같은 일반 토큰 위치를 공급했다. native FA2에서 해당 마스크가 전달되지 않고 두 분기 로짓이 같아 CFG가 conditional 점수로 환원되는 것을 실행 중 검사했다. STEP83에서 같은 conditional 위치인데도 B1과 N의 첫 층 실제 RoPE 주파수와 cosine 해시가 8/8 달랐다. STEP84에서는 이 진단을 전체 문항으로 확장했고, 각 문항의 GT/Draft 핵심 입력을 대조해 Draft 대표 B2 OFF/ON을 생성했다. 기존 STEP83 B2 토큰열은 16/16 재현했다. B2−B1 대비는 분기 위치와 공유 RoPE 구간을 함께 바꾸는 개입의 점수 차이다.

B2의 CLOSED OFF/ON은 **67.31 / 71.63**, OPEN은 **43.68 / 41.78**이다. 표의 값은 점수 차이와 95% 이미지 군집 bootstrap 구간이며, 10,000회 복원추출(seed 20261122)로 각 대비별 구간을 계산했다. CLOSED 416문항, OPEN 645문항이고 각각 96개 이미지에 걸쳐 있다.

| 대비 | CLOSED 점 [95% 구간] | OPEN 점 [95% 구간] |
|---|---:|---:|
| B2 ON − B2 OFF | +4.33 [+1.46, +7.41] | -1.90 [-4.32, +0.61] |
| B2 OFF − Draft B1 OFF | +1.20 [-1.65, +3.96] | -1.46 [-3.48, +0.55] |
| Draft actual bias OFF − B2 OFF | +0.72 [-1.46, +3.03] | +0.44 [-1.25, +2.09] |
| B2 OFF − GT B1 OFF | +0.48 [-2.20, +3.12] | -1.13 [-3.16, +0.86] |
| GT actual bias OFF − B2 OFF | +1.44 [-0.99, +3.90] | -0.35 [-1.92, +1.18] |
| B2 ON − Draft B1 ON | -0.24 [-2.75, +2.36] | +2.18 [-0.19, +4.64] |
| Draft actual bias ON − B2 ON | +2.16 [+0.00, +4.34] | -0.39 [-2.49, +1.64] |
| B2 ON − GT B1 ON | -0.24 [-2.96, +2.51] | +1.31 [-1.19, +3.85] |
| GT actual bias ON − B2 ON | +0.96 [-1.67, +3.50] | -0.21 [-2.16, +1.73] |

B2−B1의 네 대비는 CLOSED와 OPEN에서 모두 구간에 0을 포함했다. OPEN에서 B2의 Temporal 하락 폭은 Draft B1보다 관측상 작았다. 사후 상호작용 대비는 +3.64점([+0.72,+6.64])이고 GT 기준은 +2.44점([−0.50,+5.57])이다. 이는 다중 비교를 보정하지 않은 탐색적 분석이다.

평균 생성 길이도 OFF→ON에서 CLOSED 62.60→139.12토큰, OPEN 66.01→106.77토큰으로 늘었다. 256토큰 길이 도달은 OFF 0개, ON CLOSED 73개·OPEN 61개였다. 길이 증가와 점수 변화 사이의 인과는 직접 시험하지 않았다.

## 점수 해석

STEP82에서 최신 CLOSED 출력 3,744개를 재채점해 기존 공식 점수를 재현했다. endpoint는 35승·12패로 23건 순증가했고 substring-only 범주의 순증가는 14건이었다. 전체 단어 일치는 공개 기준선 267건에서 후보 258건으로 감소했다. CLOSED는 정답 문자열 포함, OPEN은 정답 토큰 recall로 해석한다. 임상 정답성·환각 감소와 미공개 저자 구현의 재현 여부는 별도 질문이다. 원형 공개 B0의 padding guard 실패는 기존 공개 소스 검증에 기록되어 있다.
